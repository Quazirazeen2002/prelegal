# prelegal

A dataset of Common Paper legal document templates (`templates/`, catalogued in `catalog.json`), plus a `frontend/` Next.js app that prototypes a Mutual NDA creator: fill in a form, preview the completed NDA, and download it as a PDF.

## Frontend

From `frontend/`:

- `npm install`
- `npm run dev` — serves on `http://localhost:3000`
- `npm test` — runs the automated test suite (Vitest). See also `frontend/MANUAL_TESTING.md` for the manual test checklist.
